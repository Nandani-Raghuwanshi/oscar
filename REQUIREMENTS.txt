# BuiltCred - Complete Dependencies & Requirements

## System Requirements

### Operating System:
- Windows 10/11 (64-bit)
- macOS 10.15 or higher
- Linux (Ubuntu 20.04 LTS or higher)

### Hardware Requirements:
- **Processor:** Intel Core i3 or equivalent (minimum), i5+ recommended
- **RAM:** 4GB (minimum), 8GB+ recommended
- **Storage:** 500MB free space for application + 2GB for MongoDB
- **Network:** Stable internet connection for cloud deployments

---

## Software Prerequisites

### Required Software & Versions:

1. **Node.js**
   - Version: 18.0.0 or higher (LTS recommended)
   - Download: https://nodejs.org/
   - Verify: `node --version`

2. **npm (Node Package Manager)**
   - Version: 9.0.0 or higher (comes with Node.js)
   - Verify: `npm --version`

3. **MongoDB**
   - Version: 6.0.0 or higher
   - Download: https://www.mongodb.com/try/download/community
   - Alternative: MongoDB Atlas (cloud) - https://www.mongodb.com/cloud/atlas
   - Verify: `mongod --version`

4. **Git**
   - Version: 2.x or higher
   - Download: https://git-scm.com/downloads
   - Verify: `git --version`

### Optional Software:

1. **pnpm** (Alternative package manager - faster than npm)
   - Install: `npm install -g pnpm`
   - Verify: `pnpm --version`

2. **MongoDB Compass** (GUI for MongoDB)
   - Download: https://www.mongodb.com/try/download/compass

3. **Postman** or **Thunder Client** (API testing)
   - Postman: https://www.postman.com/downloads/
   - Thunder Client: VS Code extension

4. **VS Code** (Recommended code editor)
   - Download: https://code.visualstudio.com/

## Database Requirements

### MongoDB Configuration:

**Minimum Requirements:**
- MongoDB 6.0+
- WiredTiger storage engine
- At least 2GB free disk space
- Port 27017 available (default)

**Collections Created:**
1. users
2. projects
3. customers
4. referrals
5. rewards
6. auditlogs
7. interactions (Phase 6)
8. paymentrecords (Phase 6)
9. escalations
10. brandreferrals
11. brandrewards

**Indexes Required:**
- users: email (unique), role
- referrals: status, assignedTo, escalationLevel
- interactions: referralId, salesAssociateId
- paymentrecords: referralId, status

## Installation Steps Summary

### 1. Install System Prerequisites:
```powershell
# Install Node.js (includes npm)
# Download from: https://nodejs.org/

# Install MongoDB
# Download from: https://www.mongodb.com/try/download/community

# Install Git
# Download from: https://git-scm.com/downloads
```

### 2. Clone Repository:
```powershell
git clone https://github.com/Nandani-Raghuwanshi/oscar.git
cd oscar
```

### 3. Install Backend Dependencies:
```powershell
cd server
npm install
```

### 4. Install Frontend Dependencies:
```powershell
cd ..\client
npm install
```

### 5. Configure Environment:
```powershell
# Copy .env.example to .env
cd ..\server
copy .env.example .env

# Edit .env file with your configuration
notepad .env
```

### 6. Start MongoDB:
```powershell
# Start MongoDB service
net start MongoDB
```

### 7. Run Application:
```powershell
# Terminal 1 - Backend
cd server
npm run dev

# Terminal 2 - Frontend
cd client
npm run dev
```

## Dependency Security

### Security Best Practices:

1. **Keep Dependencies Updated:**
   ```bash
   npm outdated
   npm update
   ```

2. **Check for Vulnerabilities:**
   ```bash
   npm audit
   npm audit fix
   ```

3. **Use Package Lock:**
   - Always commit `package-lock.json` or `pnpm-lock.yaml`
   - Ensures consistent installations

4. **Environment Security:**
   - Never commit `.env` files
   - Use strong JWT secrets (64+ characters)
   - Rotate secrets regularly in production

## Production Deployment Requirements

### Additional Requirements for Production:

1. **Process Manager:**
   - PM2: `npm install -g pm2`
   - Usage: `pm2 start server/src/index.js --name builtcred-api`

2. **Reverse Proxy:**
   - Nginx (recommended) or Apache
   - For serving frontend and proxying API requests

3. **SSL Certificate:**
   - Let's Encrypt (free) or commercial SSL
   - Required for HTTPS

4. **Cloud Hosting Options:**
   - **Backend:** Heroku, AWS EC2, DigitalOcean, Render
   - **Frontend:** Netlify, Vercel, AWS S3 + CloudFront
   - **Database:** MongoDB Atlas, AWS DocumentDB

5. **Monitoring (Optional):**
   - Logging: Winston, Morgan
   - Monitoring: New Relic, DataDog
   - Error Tracking: Sentry

## Troubleshooting Common Dependency Issues

### Issue 1: npm install fails
```bash
# Clear npm cache
npm cache clean --force

# Delete node_modules and lock file
Remove-Item -Recurse -Force node_modules
Remove-Item package-lock.json

# Reinstall
npm install
```

### Issue 2: Version conflicts
```bash
# Check for outdated packages
npm outdated

# Update to latest compatible versions
npm update
```

### Issue 3: peer dependency warnings
```bash
# Install with legacy peer deps flag
npm install --legacy-peer-deps
```
