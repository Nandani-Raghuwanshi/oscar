## project name builtcred
a project with referral program for construction projects, focus on lead tracking

## Tech stack 
React js - vite pages
nodejs - backend
mongodb - database
whatsapp messages with gupshup



## BUILDER/LAND-OWNER/DEVELOPER module roles and responsibilitiess

1) upload list of customers ( send invite using whatsapp)
2) view reports and stats
3) view critical escalations

## CRM/SALES module

1) manage project advocates 
    - list and view status of advocate based on number of refferals he generated or not
2) Sales manager level to assign referrals to associate
3) track status on each step
4) escalate for cases with no progress
note- unattended lead buckets, add note on each step atleat 50 words
5) level 2 sales associate initiate calls, engage with customers, mark status daily
6) mark payment status

## Project advocates module roles and responsibilities

1) view his own project/property documentations, status updates and certifications

2) send referrals to friends, view conversions, rewards status

## Brand advocates module 
    all same to project but for him he can refer to only our target project


## admin
1) can create users at all levels
2) can create different projects
3) can access all details on all levels
4) can view all escalations
5) send updates to users using whatspp
