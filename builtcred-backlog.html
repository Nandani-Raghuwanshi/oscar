BuiltCred – Product Backlog

MVP v2.0 · Phase 1 (Months 1–3)

Last Updated: February 13, 2026 · Status: Development Phase

🎯 Product Vision

BuiltCred is a referral management platform for real estate developers that enables customer advocacy through a dual-advocate system (Project Advocates & Brand Advocates), providing validation, tracking, reward management, and CRM integration.

Module 1: Core Advocate System

Priority: P0 · Sprints: 1–3

📘 Module Description

Foundational identity layer defining Project Advocates and Brand Advocates. Controls eligibility, privacy, dashboards, analytics segmentation, and cross-developer prevention.

1.1 Advocate Type Classification

User Story

As a developer/admin
I want automatic advocate classification
So that eligibility and tracking are consistent

Acceptance Criteria

  • PROJECT_ADVOCATE and BRAND_ADVOCATE defined
  • Stored in customer profile
  • Badge visible across UI
  • Historical tracking maintained

Technical Requirements

  • `advocate_type` enum field
  • Indexed for analytics
  • Migration for existing users
1.2 Advocate Type Validation Engine
  • Runs on every referral submission
  • Cross-developer validation
  • Auto-correction when possible
  • Audit logging

validateAdvocateEligibility(userId, selectedType, targetProjectId)
1.3 Advocate Type Selection UI
  • Radio buttons
  • Clear help text
  • WCAG 2.1 AA compliant
  • Mobile responsive
1.4 Dashboard Differentiation
  • Role-based rendering
  • Strict data isolation
  • Eligible projects only
1.5 Reporting & Analytics
  • Metrics by advocate type
  • Conversion & reward comparisons
  • CSV export
1.6 Sales Context Enrichment 

if PROJECT_ADVOCATE:
  "Referred by fellow resident"
else:
  "Referred by existing customer"
1.7 Cross-Developer Validation
  • Developer ID matching
  • Rate limiting
  • Fraud audit logs

Module 2: Referral Engine

Priority: P0 · Sprints: 2–5

📘 Module Description

The Referral Engine is the core transaction and orchestration layer of BuiltCred. Module 3: Homeowner Portal

Priority: P0 · Sprints: 4–7

📘 Module Description

The Homeowner Portal is the primary interface for advocates to manage referrals, track conversions, view rewards, and maintain their profile. It is designed to be mobile-first, intuitive, and transparent to build trust and encourage repeat referrals.

3.1 Advocate Dashboard

User Story

As an advocate
I want a single dashboard view
So that I can quickly understand my referral and reward status

Features

  • Total referrals count
  • Active / converted / lost referrals
  • Total rewards earned & paid
  • Pending rewards
  • Advocate type badge (Project / Brand)
3.2 Referral List & Detail View
  • Paginated referral list
  • Status filters (NEW, CONTACTED, VISIT_DONE, CONVERTED, LOST)
  • Search by lead name / phone
  • Referral detail page with timeline
  • Read-only CRM status sync
3.3 Referral Submission
  • Simple referral form
  • Advocate type selection
  • Target project selection
  • Inline validation
  • Duplicate warning messages
3.4 Rewards Dashboard
  • Total rewards earned
  • Total rewards paid
  • Pending rewards
  • Reward breakup by referral
  • TDS deduction visibility

Gross Reward: ₹50,000

3.5 Referral Links & QR Codes
  • Unique referral link per advocate

  • Download & share options
3.6 Notifications & Updates
  • Status change notifications

3.7 Documents & Statements
